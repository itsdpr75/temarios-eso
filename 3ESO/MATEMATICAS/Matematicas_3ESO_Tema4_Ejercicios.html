Tema 4: Ejercicios

4.1 Ecuaciones racionales y bicuadradas

27 ejercicios
⭐ Básico
⭐4.1.01

Resuelve la ecuación racional $\frac{x+1}{2} + \frac{x-1}{3} = 4$.

⭐4.1.02

Resuelve $\frac{2x}{3} - \frac{x+1}{4} = 1$.

⭐4.1.03

Resuelve $\frac{3}{x} = 6$.

⭐4.1.04

Resuelve $\frac{x-2}{x+1} = 1$.

⭐4.1.05

Resuelve la ecuación bicuadrada $x^4 - 5x^2 + 4 = 0$.

⭐4.1.06

Resuelve $x^4 - 10x^2 + 9 = 0$.

⭐4.1.07

Resuelve $x^4 - 13x^2 + 36 = 0$.

⭐4.1.08

Resuelve $\frac{1}{x-1} = \frac{2}{x+1}$.

⭐4.1.09

Resuelve $\frac{x}{2} + \frac{3}{x} = 4$.

⭐4.1.10

Resuelve $x^4 - 1 = 0$.

⭐4.1.11

Resuelve la ecuación racional $\frac{5}{x} - \frac{3}{x} = 4$.

⭐4.1.12

Resuelve la ecuación bicuadrada $x^4 + 2x^2 - 3 = 0$.

⭐⭐ Intermedio
⭐⭐4.1.13

Resuelve $\frac{1}{x} + \frac{1}{x-2} = 1$ y verifica las condiciones de existencia.

⭐⭐4.1.14

Resuelve $\frac{x+1}{x-2} + \frac{x-3}{x+1} = 2$.

⭐⭐4.1.15

Resuelve la ecuación bicuadrada $x^4 - 3x^2 - 4 = 0$. ¿Cuántas soluciones reales tiene?

⭐⭐4.1.16

Resuelve $\frac{2}{x-1} - \frac{3}{x+1} = \frac{1}{x}$.

⭐⭐4.1.17

Resuelve $x^4 + x^2 - 2 = 0$ indicando cuántas soluciones reales existen.

⭐⭐4.1.18

Resuelve $\frac{x^2 - 4}{x - 2} = 5$.

⭐⭐4.1.19

Resuelve $\frac{1}{x+1} + \frac{2}{x-1} = \frac{6}{x^2-1}$.

⭐⭐4.1.20

Halla las dimensiones de un rectángulo sabiendo que su área es $12\text{ cm}^2$ y un lado mide $2\text{ cm}$ más que el otro, planteando una ecuación racional.

⭐⭐4.1.21

Resuelve $x^4 - 8x^2 + 16 = 0$. ¿Qué particularidad presenta la solución?

⭐⭐4.1.22

Resuelve $\frac{3x+1}{x-1} - \frac{x+2}{x+1} = \frac{2x}{x^2-1}$.

⭐⭐⭐ Avanzado
⭐⭐⭐4.1.23

Resuelve $\frac{x^2 + x + 1}{x + 1} = x + \frac{1}{x + 1}$ y demuestra que se simplifica a una ecuación de primer grado.

⭐⭐⭐4.1.24

Resuelve la ecuación bicuadrada $4x^4 - 5x^2 + 1 = 0$ y verifica que la suma de todas las soluciones es $0$.

⭐⭐⭐4.1.25

Resuelve $\frac{1}{x-2} + \frac{1}{x+2} + \frac{4}{x^2 - 4} = 0$.

⭐⭐⭐4.1.26

Demuestra que la ecuación $\frac{1}{x} + \frac{1}{x+1} = \frac{1}{x+2}$ no tiene solución comprobando que las posibles soluciones anulan el denominador.

⭐⭐⭐4.1.27

Resuelve $x^4 - 7x^2 + 12 = 0$ y expresa las soluciones como $\pm\sqrt{a}$ y $\pm\sqrt{b}$.

4.2 Sistemas 2x2 no lineales

25 ejercicios
⭐ Básico
⭐4.2.01

Resuelve el sistema $\{x + y = 7,\; x \cdot y = 12\}$.

⭐4.2.02

Resuelve el sistema $\{x - y = 1,\; x^2 + y^2 = 13\}$.

⭐4.2.03

Resuelve el sistema $\{x + y = 5,\; x^2 - y^2 = 5\}$.

⭐4.2.04

Resuelve el sistema $\{2x + y = 10,\; xy = 12\}$.

⭐4.2.05

Resuelve el sistema $\{x + y = 6,\; x^2 + y^2 = 20\}$.

⭐4.2.06

Resuelve el sistema $\{x - y = 2,\; x^2 - y^2 = 8\}$.

⭐4.2.07

Halla dos números cuya suma sea $10$ y cuyo producto sea $21$ planteando un sistema.

⭐4.2.08

Resuelve el sistema $\{x + y = 1,\; x^2 + y^2 = 1\}$.

⭐4.2.09

Resuelve el sistema $\{y = x^2,\; y = 2x - 1\}$.

⭐4.2.10

Resuelve el sistema $\{y = x^2 - 4,\; y = x + 2\}$.

⭐⭐ Intermedio
⭐⭐4.2.11

Resuelve el sistema $\{x^2 + y^2 = 25,\; xy = 12\}$.

⭐⭐4.2.12

Resuelve el sistema $\{x + y + xy = 11,\; x + y = 5\}$.

⭐⭐4.2.13

Resuelve el sistema $\{x^2 - y^2 = 24,\; x - y = 4\}$.

⭐⭐4.2.14

Halla dos números sabiendo que su suma es $9$ y la suma de sus cuadrados es $45$.

⭐⭐4.2.15

Resuelve el sistema $\{y = x^2 - 2x + 1,\; y = -x + 3\}$ y representa gráficamente la situación.

⭐⭐4.2.16

Resuelve $\{x^2 + y^2 = 1,\; x^2 - y^2 = 1\}$.

⭐⭐4.2.17

Resuelve $\{(x-1)^2 + y^2 = 9,\; y = x\}$.

⭐⭐4.2.18

Un rectángulo tiene perímetro $20\text{ cm}$ y área $21\text{ cm}^2$. Plantea un sistema y halla sus dimensiones.

⭐⭐4.2.19

Resuelve el sistema $\{x + y = 4,\; \frac{1}{x} + \frac{1}{y} = \frac{5}{6}\}$.

⭐⭐4.2.20

Resuelve $\{x^2 + y = 7,\; x + y^2 = 7\}$ por simetría.

⭐⭐⭐ Avanzado
⭐⭐⭐4.2.21

Resuelve $\{x^2 + y^2 = 16,\; x^2 - xy + y^2 = 7\}$.

⭐⭐⭐4.2.22

Resuelve $\{x^2 + xy + y^2 = 7,\; x^2 - xy + y^2 = 3\}$ sumando y restando las ecuaciones.

⭐⭐⭐4.2.23

Demuestra que el sistema $\{x^2 + y^2 = 1,\; xy = 1\}$ no tiene soluciones reales.

⭐⭐⭐4.2.24

Resuelve $\{x + y + z = 6,\; xy + yz + zx = 11,\; xyz = 6\}$ donde $x, y, z$ son números enteros positivos.

⭐⭐⭐4.2.25

Halla todos los pares de números naturales $(x, y)$ que satisfacen $\{x^2 - y^2 = 45,\; x - y = 5\}$.

4.3 Sistemas 3x3 lineales

25 ejercicios
⭐ Básico
⭐4.3.01

Resuelve el sistema $\{x + y + z = 6,\; x - y + z = 2,\; x + y - z = 0\}$.

⭐4.3.02

Resuelve el sistema $\{2x + y + z = 8,\; x - y + z = 2,\; x + y - z = 0\}$.

⭐4.3.03

Resuelve el sistema $\{x + y + z = 9,\; x = y + 1,\; y = z + 1\}$.

⭐4.3.04

Resuelve el sistema $\{x + y = 5,\; y + z = 7,\; x + z = 6\}$.

⭐4.3.05

Resuelve el sistema $\{x + 2y + 3z = 14,\; x - y + z = 2,\; 2x + y - z = 1\}$.

⭐4.3.06

Resuelve el sistema $\{x + y + z = 3,\; 2x - y + z = 2,\; x + 2y - z = 0\}$.

⭐4.3.07

Resuelve el sistema $\{3x + y - z = 1,\; x - 2y + z = 4,\; 2x + y + z = 5\}$.

⭐4.3.08

Resuelve el sistema $\{x + y = 3,\; y + z = 5,\; z + x = 4\}$.

⭐4.3.09

Resuelve el sistema $\{x = 2y,\; y = 3z,\; x + y + z = 30\}$.

⭐4.3.10

Resuelve el sistema $\{x + y + z = 12,\; x - y = 2,\; y - z = 1\}$.

⭐⭐ Intermedio
⭐⭐4.3.11

Resuelve por reducción el sistema $\{2x + y - z = 3,\; x - y + 2z = 6,\; 3x + 2y + z = 7\}$.

⭐⭐4.3.12

Resuelve $\{x + 2y - z = 1,\; 3x - y + z = 4,\; 2x + y - 2z = -1\}$.

⭐⭐4.3.13

Determina si el sistema $\{x + y + z = 1,\; 2x + 2y + 2z = 2,\; 3x + 3y + 3z = 3\}$ es compatible determinado, compatible indeterminado o incompatible.

⭐⭐4.3.14

Un comerciante vende tres tipos de manzanas: A a $2\text{ €/kg}$, B a $3\text{ €/kg}$ y C a $5\text{ €/kg}$. En total vende $20\text{ kg}$ por $72\text{ €}$. Si vende el doble de kg del tipo A que del tipo C, ¿cuántos kg de cada tipo vende?

⭐⭐4.3.15

Resuelve $\{x + y + z = 0,\; 2x - y + 3z = 5,\; x + 3y - z = -2\}$.

⭐⭐4.3.16

En una familia, la suma de las edades de padre, madre e hijo es $90$ años. Hace $5$ años, la suma era $70$ años. El padre es $6$ años mayor que la madre. Halla las edades actuales.

⭐⭐4.3.17

Resuelve $\{x - 2y + z = -1,\; 3x + y - 2z = 7,\; -x + y + 3z = 5\}$.

⭐⭐4.3.18

Tres números suman $48$. El doble del primero más el segundo igual al tercero. El primero más el doble del tercero igual a $60$. Halla los tres números.

⭐⭐4.3.19

Resuelve $\{x + 3y - z = 5,\; 2x - y + 2z = 4,\; -x + y + z = -1\}$.

⭐⭐4.3.20

Un depósito de $1000$ litros se llena con tres grifos. El primero aporta el doble que el segundo, y el tercero aporta $200$ litros más que el segundo. ¿Cuántos litros aporta cada grifo?

⭐⭐⭐ Avanzado
⭐⭐⭐4.3.21

Demuestra que el sistema $\{x + y + z = 1,\; x + y + z = 2,\; x + y + z = 3\}$ es incompatible.

⭐⭐⭐4.3.22

Resuelve el sistema $\{x + y + z = a,\; x - y + z = b,\; x + y - z = c\}$ expresando $x$, $y$, $z$ en función de $a$, $b$, $c$.

⭐⭐⭐4.3.23

Halla tres números consecutivos cuya suma sea $33$ y cuya suma de cuadrados sea $385$ planteando un sistema.

⭐⭐⭐4.3.24

Resuelve $\{2x + 3y - z = 1,\; x - y + 2z = 3,\; 3x + 2y + z = 4\}$ y verifica que la solución satisface las tres ecuaciones.

⭐⭐⭐4.3.25

Un sistema 3x3 tiene solución $(1, -2, 3)$. Si las ecuaciones son $ax + by + cz = d$, $ex + fy + gz = h$ y $ix + jy + kz = l$, escribe un sistema que tenga exactamente esa solución con coeficientes sencillos.

4.4 Inecuaciones de primer grado y representación

27 ejercicios
⭐ Básico
⭐4.4.01

⭐4.4.05

Resuelve $5 - 3x > 11$ y representa la solución.

⭐4.4.07

Resuelve $-x + 4 < -2$ y representa la solución.

⭐4.4.08

Resuelve $3(x - 2) \geq x + 4$ y representa la solución.

⭐4.4.09

Resuelve $\frac{2x - 1}{3} < \frac{x + 2}{2}$ y representa la solución.

⭐4.4.10

Resuelve $7x > 0$ y representa la solución.

⭐4.4.11

Resuelve $-4x \leq 0$ y representa la solución.

⭐4.4.12

⭐⭐ Intermedio
⭐⭐4.4.13

Resuelve el sistema de inecuaciones $\{x + 3 > 0,\; 2x - 4 \leq 0\}$.

⭐⭐4.4.14

⭐⭐4.4.15

Resuelve $\{3x - 1 < 8,\; x + 2 > -1,\; 2x \leq 6\}$.

⭐⭐4.4.16

Halla el dominio de la expresión $\sqrt{x - 3}$.

⭐⭐4.4.17

⭐⭐4.4.18

⭐⭐4.4.19

⭐⭐4.4.20

⭐⭐4.4.21

⭐⭐4.4.22

Resuelve $x^2 - 5x + 6 \geq 0$.

⭐⭐⭐ Avanzado
⭐⭐⭐4.4.23

⭐⭐⭐4.4.24

Resuelve $\frac{x^2 - 4}{x - 1} \leq 0$.

⭐⭐⭐4.4.25

Halla todos los valores de $m$ para que la ecuación $x^2 + mx + 1 = 0$ tenga dos soluciones reales distintas.

⭐⭐⭐4.4.26

Resuelve $\frac{x + 3}{x - 1} \geq \frac{2x}{x + 1}$.

⭐⭐⭐4.4.27

Un número natural $n$ satisface que el doble de $n$ es menor que $15$ y que $n^2$ es mayor que $16$. Halla todos los posibles valores de $n$.
