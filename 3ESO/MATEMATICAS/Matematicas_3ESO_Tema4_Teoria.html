4.1 Ecuaciones racionales y bicuadradas

Además de las ecuaciones de primer y segundo grado, existen otros tipos de ecuaciones que se resuelven mediante técnicas específicas. Las ecuaciones racionales incluyen fracciones algebraicas en uno o ambos miembros, mientras que las ecuaciones bicuadradas son ecuaciones de cuarto grado que pueden transformarse en ecuaciones de segundo grado mediante un cambio de variable. Dominar estos métodos amplía enormemente la capacidad de resolución de problemas matemáticos.

Ecuaciones racionales

Una ecuación racional es aquella en la que la incógnita aparece en el denominador de una o varias fracciones algebraicas. Para resolverlas se sigue este procedimiento:

  • Se identifican las condiciones de existencia: los valores de $x$ que anulan algún denominador no pueden ser soluciones.
  • Se multiplican ambos miembros de la ecuación por el mínimo común denominador para eliminar las fracciones.
  • Se resuelve la ecuación resultante (que puede ser de primer o segundo grado).
  • Se comprueba que las soluciones obtenidas no estén excluidas del dominio.
  • Ejemplo: para resolver $\frac{1}{x} + \frac{1}{x-1} = \frac{3}{2}$, el m.c.m. de los denominadores es $2x(x-1)$. Multiplicando y simplificando se obtiene una ecuación de segundo grado.
  • Si una solución obtenida anula un denominador, se denomina solución extraña y debe descartarse.
$$\frac{A(x)}{B(x)} = \frac{C(x)}{D(x)} \implies A(x) \cdot D(x) = B(x) \cdot C(x)$$

Ecuaciones bicuadradas

Una ecuación bicuadrada tiene la forma $ax^4 + bx^2 + c = 0$, donde solo aparecen potencias pares de $x$. Se resuelve mediante el cambio de variable $t = x^2$, que transforma la ecuación en una de segundo grado:

$$at^2 + bt + c = 0$$
  • Se resuelve la ecuación en $t$ y se obtienen las soluciones $t_1$ y $t_2$.
  • Si $t_i \geq 0$, se deshace el cambio: $x = \pm\sqrt{t_i}$, lo que da dos soluciones reales.
  • Si $t_i < 0$, no hay soluciones reales asociadas a ese valor de $t$.
  • Una ecuación bicuadrada puede tener 0, 2 o 4 soluciones reales.
  • Ejemplo: $x^4 - 5x^2 + 4 = 0$. Con $t = x^2$: $t^2 - 5t + 4 = 0$, de donde $t = 1$ o $t = 4$. Las soluciones son $x = \pm 1$ y $x = \pm 2$.
Aplicación práctica

Las ecuaciones racionales aparecen en problemas de mezclas (concentraciones), en circuitos eléctricos (resistencias en paralelo) y en la determinación de tiempos en problemas de velocidad. Las ecuaciones bicuadradas se utilizan en física para describir el movimiento parabólico y en el cálculo de energías en mecánica cuántica.

4.2 Sistemas 2x2 no lineales

Un sistema de ecuaciones es no lineal cuando al menos una de las ecuaciones no es de primer grado. Los sistemas 2x2 no lineales pueden incluir ecuaciones de segundo grado, ecuaciones racionales o productos de variables. Su resolución suele requerir técnicas de sustitución más elaboradas que las de los sistemas lineales.

Sistemas con una ecuación lineal y una cuadrática

Cuando el sistema tiene una ecuación lineal y una de segundo grado, el método más eficaz es la sustitución:

  • Se despeja una incógnita de la ecuación lineal.
  • Se sustituye en la ecuación de segundo grado.
  • Se resuelve la ecuación resultante.
  • Se obtienen los pares de soluciones $(x, y)$ correspondientes.
  • Ejemplo: el sistema $x + y = 5$, $x^2 + y^2 = 13$. Despejando $y = 5 - x$ y sustituyendo: $x^2 + (5-x)^2 = 13$.
  • Es posible obtener 0, 1 o 2 soluciones del sistema.
  • Geométricamente, representa la intersección de una recta con una parábola o una circunferencia.

Sistemas con dos ecuaciones de segundo grado

Cuando ambas ecuaciones son de segundo grado, la resolución puede ser más compleja:

  • Se puede intentar sumar o restar las ecuaciones para eliminar términos.
  • También se puede sustituir una variable expresada desde una ecuación en la otra.
  • En algunos casos, es útil multiplicar una ecuación por un número para facilitar la eliminación.
  • El número de soluciones puede ser 0, 1, 2, 3 o 4 (como máximo), ya que geométricamente representa la intersección de dos cónicas.
  • Ejemplo: $x^2 + y^2 = 25$ y $xy = 12$. Se pueden buscar soluciones enteras o aplicar sustitución con $y = \frac{12}{x}$.
$$ \begin{cases} ax^2 + bxy + cy^2 + dx + ey + f = 0 \\ a'x^2 + b'xy + c'y^2 + d'x + e'y + f' = 0 \end{cases} $$
Aplicación práctica

Los sistemas no lineales aparecen en geometría analítica (intersección de circunferencias, parábolas y rectas), en economía (puntos de equilibrio con funciones de oferta y demanda no lineales) y en ingeniería (diseño de engranajes y mecanismos).

4.3 Sistemas 3x3 lineales

Un sistema de tres ecuaciones con tres incógnitas se denomina sistema 3×3 lineal. Estos sistemas aparecen frecuentemente en problemas reales que involucran tres variables interrelacionadas, como la mezcla de tres sustancias, la resolución de circuitos eléctricos o el equilibrio de fuerzas en tres dimensiones.

Método de sustitución

El método de sustitución para sistemas 3×3 consiste en:

  • Despejar una variable de una de las ecuaciones.
  • Sustituir la expresión obtenida en las otras dos ecuaciones.
  • Se obtiene un sistema 2×2 con las dos incógnitas restantes.
  • Resolver ese sistema 2×2 y obtener el valor de las tres incógnitas por sustitución sucesiva.
  • Es conveniente despejar la variable cuyo coeficiente sea $1$ o $-1$ para simplificar los cálculos.
  • La verificación de la solución se realiza sustituyendo los tres valores en las ecuaciones originales.

Método de reducción (Gauss)

El método de reducción (o método de Gauss) transforma el sistema en una forma escalonada donde cada ecuación tiene una incógnita menos que la anterior:

  • Se combinan parejas de ecuaciones para eliminar una variable.
  • Se obtiene un sistema equivalente con dos ecuaciones y dos incógnitas.
  • Se resuelve el sistema 2×2 resultante.
  • Se sustituye para hallar la tercera incógnita.
  • Ejemplo: si el sistema es $\begin{cases} x + y + z = 6 \\ 2x - y + z = 3 \\ x + 2y - z = 2 \end{cases}$, se pueden sumar la primera y la tercera ecuación para eliminar $z$.
  • Un sistema 3×3 puede ser compatible determinado (una solución), compatible indeterminado (infinitas soluciones) o incompatible (sin solución).
  • El sistema es incompatible determinado si las tres ecuaciones representan tres planos que se cortan en un solo punto.
$$ \begin{cases} a_1x + b_1y + c_1z = d_1 \\ a_2x + b_2y + c_2z = d_2 \\ a_3x + b_3y + c_3z = d_3 \end{cases} $$
Aplicación práctica

Los sistemas 3×3 se utilizan en la resolución de circuitos eléctricos con tres mallas (leyes de Kirchhoff), en la determinación de la composición de aleaciones con tres componentes y en la obtención de la ecuación de un plano a partir de tres puntos.

4.4 Inecuaciones de primer grado y representación

Una inecuación es una desigualdad entre dos expresiones algebraicas que contiene una o varias incógnitas. Resolver una inecuación es encontrar el conjunto de valores de la incógnita que hacen cierta la desigualdad. Las inecuaciones se representan gráficamente sobre la recta real y son fundamentales para comprender el comportamiento de funciones y resolver restricciones en problemas reales.

Resolución de inecuaciones de primer grado

Para resolver una inecuación de primer grado se aplican las mismas propiedades que en las ecuaciones, con una excepción crucial:

  • Si se multiplica o divide ambos miembros por un número negativo, el sentido de la desigualdad se invierte.
  • Se pueden sumar o restar el mismo número en ambos miembros sin cambiar el sentido.
  • Ejemplo: $-3x > 6 \implies x < -2$ (se divide por $-3$ y se invierte el sentido).
  • Las soluciones se expresan como intervalos: $x < -2$ se escribe como $(-\infty, -2)$.
  • Tipos de desigualdades: $<$ (menor que), $>$ (mayor que), $\leq$ (menor o igual que), $\geq$ (mayor o igual que).

Representación gráfica en la recta real

Las soluciones de una inecuación se representan sobre la recta real:

  • Se dibuja una línea horizontal que representa los números reales.
  • El intervalo solución se sombrea o se marca con una flecha.
  • Si el extremo está incluido ($\leq$ o $\geq$), se usa un punto relleno (●).
  • Si el extremo no está incluido ($<$ o $>$), se usa un círculo vacío (○).
  • Ejemplo: $x \geq 3$ se representa con un punto relleno en $3$ y una flecha hacia la derecha.
  • Ejemplo: $-2 < x \leq 5$ se representa con un círculo vacío en $-2$, un punto relleno en $5$ y la zona entre ambos sombreada.

Sistemas de inecuaciones

Un sistema de inecuaciones es un conjunto de dos o más inecuaciones que deben cumplirse simultáneamente:

  • Se resuelve cada inecuación por separado.
  • La solución del sistema es la intersección de todas las soluciones individuales.
  • Se representa cada solución en la recta real y se identifica la zona común.
  • Si no hay zona común, el sistema no tiene solución.
$$x > 2 \quad \text{y} \quad x \leq 5 \implies x \in (2, 5]$$
Aplicación práctica

Las inecuaciones se usan en la planificación de presupuestos (gasto máximo permitido), en el diseño de recipientes (volumen mínimo necesario), en la programación lineal para optimizar recursos y en la definición del dominio de funciones (donde las expresiones bajo raíces cuadradas deben ser no negativas).
