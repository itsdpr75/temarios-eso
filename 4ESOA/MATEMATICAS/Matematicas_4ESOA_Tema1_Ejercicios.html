Tema 1: Ejercicios

1.1 Intervalos, semirrectas y valor absoluto

27 ejercicios
⭐ Básico
⭐1.1.01

Escribe como intervalo el conjunto $\{x \in \mathbb{R} \mid -3 \leq x < 7\}$.

⭐1.1.02

Representa en la recta real el intervalo $(-5, 2]$.

⭐1.1.03

Calcula $|5|$, $|-13|$ y $|0|$.

⭐1.1.04

Calcula $|2x - 6|$ para $x = 5$ y para $x = 1$.

⭐1.1.05

Expresa mediante valor absoluto la distancia entre $-4$ y $7$.

⭐1.1.06

Halla el conjunto solución de $|x| = 8$.

⭐1.1.07

Halla el conjunto solución de $|x| \leq 3$ y represéntalo como intervalo.

⭐1.1.08

Halla el conjunto solución de $|x| > 5$.

⭐1.1.09

Escribe la unión $(-\infty, 2] \cup [5, +\infty)$ como dos intervalos.

⭐1.1.10

Determina si el número $\sqrt{5}$ pertenece al intervalo $(2, 3)$.

⭐1.1.11

Calcula $|-3| \cdot |4|$ y verifica que es igual a $|-3 \cdot 4|$.

⭐1.1.12

Escribe como intervalo el conjunto $\{x \in \mathbb{R} \mid x \geq -1\}$.

⭐⭐ Intermedio
⭐⭐1.1.13

Resuelve la ecuación $|2x - 5| = 7$.

⭐⭐1.1.14

Resuelve la inecuación $|3x + 1| \leq 10$.

⭐⭐1.1.15

Resuelve la inecuación $|x - 4| > 3$.

⭐⭐1.1.16

Resuelve la ecuación $|x^2 - 9| = 0$.

⭐⭐1.1.17

Halla el intervalo intersección de $[-2, 6)$ y $(0, 8]$.

⭐⭐1.1.18

Demuestra que $\left|\frac{a}{b}\right| = \frac{|a|}{|b|}$ para $a = -12$ y $b = -4$.

⭐⭐1.1.19

Resuelve $|2x + 3| = |x - 1|$.

⭐⭐1.1.20

Si $|x - 2| < 4$, determina los valores que puede tomar $x$.

⭐⭐1.1.21

Resuelve la inecuación $|1 - 3x| \geq 5$.

⭐⭐1.1.22

Representa en la recta real la solución de $|x + 1| \leq 2$.

⭐⭐⭐ Avanzado
⭐⭐⭐1.1.23

Demuestra que si $|x - a| < \varepsilon$ entonces $a - \varepsilon < x < a + \varepsilon$.

⭐⭐⭐1.1.24

Resuelve la inecuación $|x - 3| + |x + 2| \leq 10$ analizando por intervalos.

⭐⭐⭐1.1.25

Halla todos los valores de $k$ para que la ecuación $|x - 3| = k$ tenga exactamente dos soluciones.

⭐⭐⭐1.1.26

Si $|a + b| = |a| + |b|$, ¿qué se puede afirmar sobre el signo de $a$ y $b$? Demuéstralo.

⭐⭐⭐1.1.27

Resuelve la ecuación $|x^2 - 5x + 6| = 2$.

1.2 Propiedades de la desigualdad

27 ejercicios
⭐ Básico

Resuelve la inecuación $2x + 3 > 7$.

⭐1.2.02

Resuelve la inecuación $-4x \leq 12$.

⭐1.2.03

Resuelve $3(x - 2) < x + 4$.

⭐1.2.04

Representa la solución de $x + 1 \geq 5$ como intervalo.

⭐1.2.05

¿Es cierta la afirmación "si $a < b$ entonces $a^2 < b^2$"? Pon un contraejemplo si no lo es.

⭐1.2.06

Resuelve $5 - 2x > 0$.

⭐1.2.07

Ordena de menor a mayor: $\sqrt{3}$, $2$, $\sqrt{5}$, $1{,}8$.

⭐1.2.08

Resuelve $\frac{x}{3} + 1 \leq \frac{x - 1}{2}$.

⭐1.2.09

⭐1.2.10

⭐1.2.11

Resuelve $4x - 3 \geq 2x + 5$ y expresa la solución como intervalo.

⭐1.2.12

Demuestra que $a^2 + 1 \geq 1$ para todo $a \in \mathbb{R}$.

⭐⭐ Intermedio
⭐⭐1.2.13

Resuelve la inecuación cuadrática $x^2 - 5x + 6 < 0$.

⭐⭐1.2.14

Resuelve $x^2 - 4x + 4 \geq 0$.

⭐⭐1.2.15

Resuelve $-x^2 + 2x + 3 > 0$.

⭐⭐1.2.16

Halla el dominio de $f(x) = \sqrt{x^2 - 9}$.

⭐⭐1.2.17

Halla el dominio de $g(x) = \frac{1}{x^2 - 5x + 6}$.

⭐⭐1.2.18

Demuestra que para $a, b \geq 0$: $\frac{a + b}{2} \geq \sqrt{ab}$ con $a = 4$ y $b = 9$.

⭐⭐1.2.19

Resuelve $\frac{x + 1}{x - 2} \geq 0$.

⭐⭐1.2.20

Resuelve $(x - 1)(x + 3)(x - 5) < 0$.

⭐⭐1.2.21

Demuestra que $(a - b)^2 \geq 0$ para todo $a, b \in \mathbb{R}$.

⭐⭐1.2.22

Resuelve la inecuación $x^2 + 1 > 0$. ¿Cuál es su solución?

⭐⭐⭐ Avanzado
⭐⭐⭐1.2.23

Demuestra la desigualdad $\frac{a^2 + b^2}{2} \geq \left(\frac{a + b}{2}\right)^2$ para $a, b \in \mathbb{R}$.

⭐⭐⭐1.2.24

Halla todos los valores de $m$ para que $x^2 - mx + 1 > 0$ sea cierta para todo $x \in \mathbb{R}$.

⭐⭐⭐1.2.25

Si $a + b = 10$ con $a, b > 0$, demuestra que $ab \leq 25$. ¿Cuándo se alcanza la igualdad?

⭐⭐⭐1.2.26

Resuelve $\frac{x^2 - 3x + 2}{x^2 + 1} \leq 0$.

⭐⭐⭐1.2.27

Demuestra que $a^4 + b^4 \geq a^2b^2 + a^2b^2$ para $a, b \in \mathbb{R}$ (desigualdad de las potencias).

1.3 Entorno, límites intuitivos y asíntotas

27 ejercicios
⭐ Básico
⭐1.3.01

Escribe el entorno de centro $3$ y radio $0{,}5$ como intervalo.

⭐1.3.02

Escribe formalmente el entorno de centro $-1$ y radio $0{,}01$.

⭐1.3.03

¿Es $x = 2$ un punto del entorno reducido de centro $2$ y radio $1$?

⭐1.3.04

Calcula intuitivamente $\lim_{x \to 3} (2x + 1)$.

⭐1.3.05

Calcula intuitivamente $\lim_{x \to 0} x^2$.

⭐1.3.06

Halla las asíntotas verticales de $f(x) = \frac{1}{x - 3}$.

⭐1.3.07

Halla la asíntota horizontal de $f(x) = \frac{5}{x + 1}$.

⭐1.3.08

¿Cuál es $\lim_{x \to +\infty} \frac{1}{x}$?

⭐1.3.09

Representa la función $f(x) = \frac{1}{x}$ e indica sus asíntotas.

⭐1.3.10

Escribe el entorno reducido de centro $0$ y radio $\varepsilon = 2$.

⭐1.3.11

Si $\lim_{x \to 2} f(x) = 5$ y $\lim_{x \to 2} g(x) = 3$, ¿cuánto vale $\lim_{x \to 2} (f + g)(x)$?

⭐1.3.12

Calcula $\lim_{x \to 1} \frac{x^2 - 1}{x - 1}$ justificando tu respuesta.

⭐⭐ Intermedio
⭐⭐1.3.13

Calcula $\lim_{x \to 2} \frac{x^2 - 4}{x - 2}$.

⭐⭐1.3.14

Estudia los límites laterales de $f(x) = \frac{|x|}{x}$ en $x = 0$. ¿Existe el límite?

⭐⭐1.3.15

Halla las asíntotas de $f(x) = \frac{2x + 1}{x - 3}$.

⭐⭐1.3.16

Calcula $\lim_{x \to +\infty} \frac{3x^2 - x + 1}{2x^2 + 5}$.

⭐⭐1.3.17

Estudia $\lim_{x \to 0} \frac{\sqrt{x + 4} - 2}{x}$.

⭐⭐1.3.18

¿Cuánto vale $\lim_{x \to +\infty} \frac{x}{x + 1}$? Justifica.

⭐⭐1.3.19

Sea $f(x) = \frac{x^2 - 9}{x^2 + 9}$. Halla sus asíntotas horizontales.

⭐⭐1.3.20

Calcula $\lim_{x \to -1} \frac{x^3 + 1}{x + 1}$.

⭐⭐1.3.21

¿Es $\lim_{x \to 0} \sin\left(\frac{1}{x}\right)$ un límite determinado? Justifica.

⭐⭐1.3.22

Halla las asíntotas de $f(x) = \frac{x^2}{x^2 - 4}$.

⭐⭐⭐ Avanzado
⭐⭐⭐1.3.23

Calcula $\lim_{x \to 0} \frac{1 - \cos x}{x^2}$ sabiendo que vale $\frac{1}{2}$.

⭐⭐⭐1.3.24

Demuestra que $\lim_{x \to 0} x \cdot \sin\left(\frac{1}{x}\right) = 0$ usando la propiedad de acotamiento.

⭐⭐⭐1.3.25

⭐⭐⭐1.3.26

Halla todas las asíntotas de $f(x) = \frac{x^3 + 1}{x^2 - 1}$.

⭐⭐⭐1.3.27

Estudia el límite $\lim_{x \to 0} \frac{e^x - 1}{x}$ sabiendo que vale $1$.

1.4 Continuidad y discontinuidad de funciones

27 ejercicios
⭐ Básico
⭐1.4.01

¿Es continua la función $f(x) = 3x^2 - 2x + 1$ en todo $\mathbb{R}$? Justifica.

⭐1.4.02

¿Es continua $f(x) = \frac{1}{x}$ en $x = 3$? ¿Y en $x = 0$?

⭐1.4.03

Estudia la continuidad de $f(x) = \frac{x + 1}{x - 2}$ en $x = 2$.

⭐1.4.04

¿En qué punto es discontinua $f(x) = \sqrt{x - 1}$?

⭐1.4.05

Determina si $f(x) = |x|$ es continua en $x = 0$.

⭐1.4.06

¿Cuánto vale $f(0)$ si $f(x) = \frac{x^2 - 4}{x - 2}$ está definida para $x \neq 2$?

⭐1.4.07

¿Es continua la función $f(x) = \pi$ en todo $\mathbb{R}$?

⭐1.4.08

Estudia la continuidad de $f(x) = \frac{1}{x^2 + 1}$.

⭐1.4.09

Nombra un tipo de discontinuidad y pon un ejemplo.

⭐1.4.10

Si $f$ es continua en $x = a$, ¿qué relación hay entre $\lim_{x \to a} f(x)$ y $f(a)$?

⭐1.4.11

¿Es la función $f(x) = \lfloor x \rfloor$ (parte entera) continua en $x = 2{,}5$?

⭐1.4.12

¿Cuáles son los puntos de discontinuidad de $f(x) = \frac{2x}{x^2 - 9}$?

⭐⭐ Intermedio
⭐⭐1.4.13

Estudia la continuidad de $f(x) = \frac{x^2 - 4}{x - 2}$ en todo $\mathbb{R}$ y clasifica la discontinuidad.

⭐⭐1.4.14

Si $f(x) = \begin{cases} x^2 & \text{si } x \neq 0 \\ 1 & \text{si } x = 0 \end{cases}$, ¿es $f$ continua en $x = 0$?

⭐⭐1.4.15

Determina los puntos de discontinuidad de $f(x) = \frac{x + 1}{x^2 - 5x + 6}$.

⭐⭐1.4.16

Aplica el teorema de Bolzano para demostrar que $f(x) = x^3 - 2x - 5$ tiene una raíz en $[2, 3]$.

⭐⭐1.4.17

Estudia la continuidad de $f(x) = \begin{cases} \frac{x^2 - 1}{x - 1} & \text{si } x \neq 1 \\ 3 & \text{si } x = 1 \end{cases}$.

⭐⭐1.4.18

¿Qué tipo de discontinuidad presenta $f(x) = \frac{1}{(x - 1)^2}$ en $x = 1$?

⭐⭐1.4.19

Estudia la continuidad de $f(x) = \frac{\sqrt{x + 1}}{x - 3}$.

⭐⭐1.4.20

Si $f$ es continua en $[0, 2]$ con $f(0) = -1$ y $f(2) = 3$, ¿puedes asegurar que $f(c) = 0$ para algún $c$?

⭐⭐1.4.21

Estudia la continuidad de $f(x) = \frac{|x - 2|}{x - 2}$ en $x = 2$.

⭐⭐1.4.22

Sea $f(x) = \frac{x^3 - 8}{x - 2}$. Redefine $f(2)$ para que $f$ sea continua en todo $\mathbb{R}$.

⭐⭐⭐ Avanzado
⭐⭐⭐1.4.23

Sea $f(x) = \begin{cases} \dfrac{\sin x}{x} & \text{si } x \neq 0 \\ k & \text{si } x = 0 \end{cases}$. Determina $k$ para que $f$ sea continua en $x = 0$, sabiendo que $\lim_{x \to 0}\frac{\sin x}{x} = 1$.

⭐⭐⭐1.4.24

Demuestra que la ecuación $e^x = 3 - x$ tiene al menos una solución real.

⭐⭐⭐1.4.25

Sea $f(x) = \begin{cases} \dfrac{x^2 + ax + b}{x - 1} & \text{si } x \neq 1 \\ 5 & \text{si } x = 1 \end{cases}$. Halla $a$ y $b$ para que $f$ sea continua en todo $\mathbb{R}$.

⭐⭐⭐1.4.26

Demuestra que $f(x) = x^5 + x - 1$ tiene exactamente una raíz real.

⭐⭐⭐1.4.27

Sea $f(x) = \begin{cases} x^2 \sin\left(\dfrac{1}{x}\right) & \text{si } x \neq 0 \\ 0 & \text{si } x = 0 \end{cases}$. Demuestra que $f$ es continua en $x = 0$.
